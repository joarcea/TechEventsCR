# TechEvents CR

Sitio web que muestra eventos de tecnología en Costa Rica, permite inscribirse y controla los cupos disponibles. Proyecto del curso ISW-521 Programación en Ambiente Web I (Semana 5).

## Descripción y tecnologías
El sitio genera tarjetas de eventos dinámicamente con JavaScript (DOM), descuenta cupos al presionar "Inscribirme", resalta tarjetas al pasar el mouse y tiene una sección de inscripción rápida. Tecnologías: HTML5, CSS3 (variables, Grid, media queries), JavaScript y GitHub Pages. El proyecto incluye un ejercicio de debugging documentado en `DEBUG.md`.
